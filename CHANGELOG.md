# Changelog

## 0.2.0

- Añade una vista propia de Ovi Git en la barra de actividad.
- Muestra repositorio, rama actual y cambios locales en el panel lateral.
- Permite crear ramas, cambiar entre ramas locales y confirmar todos los cambios.
- Compara una rama seleccionada con la rama actual y abre sus archivos en el visor diff.
- Mantiene el gráfico completo en una pestaña amplia del editor.
